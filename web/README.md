# OMMT — OyasaiMusicMidiTranslator

MIDIファイルをブラウザ内で解析し、OyasaiMusic専用の`.oyasai`ファイルへ変換する静的Webアプリです。MIDIファイルや変換内容を外部サーバーへ送信しません。

編集状態も配信元へ送信せず、同じブラウザプロフィールのIndexedDBへ最新セッションを1件保存します。同じ端末・同じブラウザではページを閉じても復元できますが、別端末・別ブラウザとの同期やアカウント共有は行いません。

## 主な機能

- Standard MIDI File Type 0 / 1
- テンポ変更を含む絶対発音時刻の計算
- General MIDI音色・打楽器から音ブロック16楽器への変換
- 音域外ノートのオクターブ移動、削除、端への固定
- MIDIベロシティ、チャンネル音量、Expression、Panの反映
- 白鍵・黒鍵を色分けした左鍵盤と、F♯を強調したDAW型ピアノロール
- MIDIの拍子・テンポに追従する小節ルーラーと、クリック位置からの試聴
- ピアノロール上のクリック・ドラッグ選択、鍵盤クリックでの単音確認
- 時刻範囲と音域を組み合わせた選択
- 選択した1音または複数音を新しい出力パートへ分割、または既存の別パートへ移動
- 複数MIDIの同時開始での重ね合わせ、または末尾への連結
- 全パート重ね合わせ表示と、パートごとの個別編集表示
- 選択ノートの時間グリッド移動、半音移動、正確な時刻・音程編集、削除
- ホイール、中央ドラッグ、右・下スクロールバーによる移動
- Ctrl＋ホイールで横拡大、Shift＋ホイールで縦拡大
- 全音階の横線と、Minecraft音ブロック音域に合わせたF♯目盛り
- 拍グリッドへ補正した範囲選択
- Velocity、Volume、Pan、Expressionのコントロールレーンと線形補間
- コントロールレーンを変換後の試聴と`.oyasai`出力へ反映
- シークバーまたはARRANGEルーラーから任意位置を指定した試聴
- Space再生・停止、Home／Endシーク、矢印キーでのノート移動などのキーボード操作
- IndexedDBへの端末内自動保存と、再訪時の編集状態復元
- 変換後の簡易試聴
- OyasaiMusic専用`.oyasai`ファイルの生成
- FAWEで読み込めるgzip圧縮Sponge Schematic v3（`.schem`）の生成
- 看板を含めず、最小発音間隔と自動BPMでタイミングを再現する音ブロックグリッド

## ピアノロールの基本操作

- 上部の小節ルーラーをクリック: その地点から再生
- Space: 再生・停止、Escape: 停止、Home / End: 先頭・末尾へ移動
- 中央でホイール: 音域を上下移動、上部ルーラーでホイール: 時間を左右移動
- Ctrl＋ホイール: 時間方向を拡大縮小、Shift＋ホイール: 音程方向を拡大縮小
- 中ボタンドラッグ: 時間・音域を自由移動
- 選択後に矢印キー: 1グリッドまたは1半音移動、Shift＋上下: 1オクターブ移動
- コントロールレーンでCtrl＋左クリック: 制御点追加、ドラッグ: 移動、右クリック: 削除

## ローカル確認

Node.js 22以降を使用します。外部パッケージのインストールは不要です。

```text
npm run dev
```

表示されたローカルURLをブラウザで開きます。

## テストと静的ビルド

```text
npm test
npm run build
```

GitHub Pagesへ公開するファイルは`dist`へ生成されます。リポジトリの`.github/workflows/pages.yml`は、`master`ブランチの`web`変更をテスト・ビルドしてPagesへ公開します。

## Minecraftへの取り込み

### `.oyasai`から直接登録する

1. OMMTで`.oyasai`をダウンロードします。
2. ファイルを`plugins/OyasaiMusic/import`へ入れます。
3. `oyasaimusic.use`と`oyasaimusic.import`権限を持つプレイヤーが`/mm import <ファイル名.oyasai>`を実行します。
4. 曲は実行者を作者とする非公開下書きとして保存されます。
5. 曲名、参考URL、レコード、価格、公開状態はOyasaiMusicの設定画面で変更します。

インポート済みのファイルは、通常`plugins/OyasaiMusic/import/processed`へ移動します。

### FAWE `.schem`をグリッド録音する

1. OMMTの「FAWE · SPONGE V3」で自動計算された実BPMを確認し、`.schem`をダウンロードします。
2. `.schem`をサーバーで設定されたFAWEのschematicフォルダーへ入れます。
3. Minecraft内で`//schem load <ファイル名>`を実行します。ワールドへ貼り付ける必要はありません。
4. プレイヤーを東向きにします。
5. OMMTに表示された実BPMで`/rec we grid <BPM>`を実行します。

グリッドは東（X正方向）が時間軸です。同じ時刻の和音はZ方向へ並び、Y方向には音ブロック1段だけを配置します。FAWEで通常看板・吊り下げ看板のJSONテキストが可視文字になる環境を避けるため、OMMTの`.schem`には看板、看板NBT、支持ブロックを一切含めません。

看板を使わないため、MIDIの音量とPanは`.schem`出力時に破棄され、`/rec we grid`の既定値である音量`100`・Pan`0`として記録されます。音量とPanを維持したい場合は`.oyasai`出力を使用してください。OyasaiMusic側の手作業で設置した看板や、別ツールで作られた看板付きSchematicの読み取り機能は変更していません。

OMMTは変換後ノートの異なる発音時刻を並べ、隣り合う時刻の最小間隔を求めます。その最小間隔がX方向の1ブロック以上になるまで基準BPMを自動的に上げ、全体の時間軸を同じ比率で広げます。端数ミリ秒による誤差は画面に表示されます。

Sponge Schematicの1辺は最大65,535ブロックです。自動計算したBPMのまま曲の時間軸が上限を超える場合、OMMTは上限へ収まる実BPMまで下げます。この場合、同じ列へ統合される発音位置の数と最大タイミング誤差を表示します。録音には、必ずダウンロード欄に表示された実BPMを使用してください。

OMMTサイト側には曲長・ファイルサイズ・ノート数の固定上限を設けていません。現在のOyasaiMusic音源リーダーには技術上の上限として1,000,000ノートがあるため、それを超える`.oyasai`はサーバーへの保存前に理由付きで拒否されます。

## 利用上の注意

OMMTはOyasaiMusic専用ツールであり、Minecraftの公式製品ではありません。利用・公開・配布にあたっては、Minecraftの利用規約およびガイドライン、MIDI楽曲の権利、サーバーの規則に従ってください。
